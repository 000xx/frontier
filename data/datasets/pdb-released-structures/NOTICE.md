# Notice for this dataset

`released-per-year.csv` is derived from the table on "PDB Statistics: Overall Growth of Released Structures Per Year" published by the RCSB Protein Data Bank at https://bioinformatics.rcsb.org/stats/growth/growth-released-structures.

## Licence

RCSB PDB states that data files in the PDB archive are available under the CC0 1.0 Universal Public Domain Dedication. The statement is on https://rcsb.org/pages/policies, read on 2026-11-09. The page also says that RCSB PDB data is presented without warranties and that RCSB PDB disclaims liability for uses of the work. The page's stated licence covers data files and programmatic API data. This table is a statistics page, not an archive file. The licence statement on the policies page is the one applied here. The page also notes that data from an integrated external resource follows that provider's own terms. This table has no such resource.

Changes: the table was reformatted into CSV, with the year, the yearly count and the cumulative total in separate columns. No values were changed.
